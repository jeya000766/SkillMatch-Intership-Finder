# SkillMatch

SkillMatch is a front-end student project that recommends internship roles based on selected skills and preferred domain.

## How to run

1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Double-click `index.html`.
3. Select skills.
4. Select a domain.
5. Click **Find My Internship**.

No Python, database, API, login, or internet connection is required.

## Current project scope

- Skill selection
- Domain selection
- Internship-role matching
- Match percentage
- Skill-gap recommendations
- Responsive dashboard UI
- Problem → Solution section

This is a front-end prototype for a 35% project/demo. A future version can add a database, real internship APIs, user login, and AI-based recommendations.
